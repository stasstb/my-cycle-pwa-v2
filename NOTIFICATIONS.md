# 📬 Система уведомлений (Notifications)

## Обзор

Приложение имеет встроенную систему локальных уведомлений, которая напоминает пользователю о необходимости выполнения ежедневных упражнений. Уведомления работают через Web Notifications API и Service Worker.

## Как это работает

### 1. Запрос разрешения (Permission)
При первом запуске приложения браузер попросит разрешение на отправку уведомлений:

```
"Мій цикл" хочет отправлять уведомления?
[Разрешить] [Запретить]
```

**Важно:** Если нажать "Запретить", уведомления можно разрешить позже в Параметрах браузера.

### 2. Ежедневные напоминания

Приложение проверяет время каждую минуту и отправляет уведомления в следующие моменты:

#### 🌅 09:00 — Добрый день!
**Содержание:** День N, название программы  
**Пример:**
```
🧡 День 7! Доброе утро!
Вульва ждет тебя. Открой приложение.
```

#### 🌆 18:00 — Вечер (Главное напоминание)
**Содержание:** День, название упражнения, время, статус выполнения  
**Примеры:**

Если день не выполнен:
```
🧡 День 7: Вульва
⏱️ 8 хв • Не забудь сегодняшний массаж!
```

Если день уже выполнен:
```
✅ День 7 завершен!
Отличная работа! Твой прогресс впечатляет.
```

#### 🌙 21:00 — Последний звонок
**Содержание:** Финальное напоминание перед сном  
**Пример:**
```
🌙 Последний звонок!
Еще есть время на сегодняшний массаж перед сном.
```

**Примечание:** Это уведомление НЕ отправляется, если день уже завершен (отмечен как ✓).

#### 💾 При первом запуске (Совет по хранилищу)
**Содержание:** Рекомендация разрешить постоянное хранилище  
**Пример:**
```
💾 Совет по сохранению данных
Разреши постоянное хранилище, чтобы данные не потерялись при очистке истории.
```

## Где видны уведомления

### Desktop (Windows/Mac/Linux)
- Уведомления появляются в **системном центре уведомлений**
- На Windows: появляются в правом нижнем углу
- На Mac: появляются в правом верхнем углу
- На Linux: зависит от DE (GNOME, KDE и т.п.)

### Android
- Уведомления появляются в **шторке уведомлений** (сверху)
- Если приложение "установлено", уведомления могут быть звуковыми

### iOS
- Уведомления появляются в **системе уведомлений**
- Могут быть звуковыми (зависит от Параметров)

## Управление уведомлениями

### Разрешить/Запретить в браузере

#### Chrome/Edge/Opera
1. Откройте приложение
2. Нажмите замок 🔒 в адресной строке
3. Найдите "Уведомления"
4. Выберите "Разрешить" или "Запретить"

#### Firefox
1. Откройте приложение
2. Нажмите ℹ️ в адресной строке
3. Найдите "Разрешения"
4. Отключите "Уведомления"

#### Safari (iOS)
1. Параметры → Уведомления
2. Найдите "Мій цикл"
3. Включите/отключите "Уведомления"

### Отключить звук (если он раздражает)
На большинстве браузеров уведомления БЕЗ звука по умолчанию.  
Если слышишь звук, проверь:
- **Chrome/Edge:** Параметры → Уведомления → Отключить звук
- **Firefox:** Параметры → Уведомления → Отключить звук
- **Safari:** Параметры → Звуки → Уведомления

## Технические детали

### API используются
- **Web Notifications API** — Отправка уведомлений
- **Service Worker** — Фоновая обработка
- **postMessage** — Коммуникация между приложением и SW

### Функции в app.js

```javascript
// 1. Запросить разрешение
await requestNotificationPermission()

// 2. Отправить уведомление
sendNotification(title, options)

// 3. Отправить через Service Worker (более надежно)
sendNotificationViaSW(title, options)

// 4. Запланировать ежедневное напоминание
scheduleDailyReminder(hour, minute, getReminderData)

// 5. Инициализировать все напоминания
initializeReminders()

// 6. Уведомить о новом дне
notifyNewDay()

// 7. Уведомить о статусе хранилища
notifyStorageStatus()
```

### Функции в sw.js

```javascript
// Обработка отправки уведомлений
self.addEventListener("message", event => {
  if (event.data?.type === "SEND_NOTIFICATION") {
    // Отправить уведомление
    self.registration.showNotification(...)
  }
})

// Обработка клика на уведомление
self.addEventListener("notificationclick", event => {
  // Открыть/фокусировать приложение
  clients.openWindow("./")
})

// Логирование закрытия
self.addEventListener("notificationclose", event => {
  console.log("Уведомление закрыто")
})
```

## Отладка

### Включить детальное логирование
Открой DevTools (F12) → Console и ищи сообщения с эмодзи:
- `📬` — Уведомление отправлено
- `✅` — Уведомления разрешены
- `❌` — Уведомления запрещены
- `⚠️` — Ошибка уведомлений

### Протестировать уведомления

Открой консоль и запусти:

```javascript
// Тест 1: Проверить разрешение
console.log("Разрешение:", Notification.permission)

// Тест 2: Отправить тестовое уведомление
sendNotification("🧡 Тест", { body: "Это тестовое уведомление" })

// Тест 3: Отправить через Service Worker
sendNotificationViaSW("🧡 Тест SW", { body: "Через Service Worker" })

// Тест 4: Запланировать на 1 минуту позже
const now = new Date()
const minute = now.getMinutes() + 1
scheduleDailyReminder(now.getHours(), minute % 60, () => ({
  title: "🧡 Тест напоминания",
  options: { body: "Напоминание работает!" }
}))
```

### Проверить логи Service Worker
1. DevTools → Application → Service Workers
2. Нажимите на активный Service Worker
3. Откроется консоль Service Worker
4. Тут видны все лог-сообщения SW

## Проблемы и решения

### Уведомления не приходят
**Проблема:** Браузер не отправляет уведомления.

**Решения:**
1. Проверь разрешение: нажми замок в адресной строке
2. Убедись, что браузер не в фокусе (уведомления видны, когда браузер в фоне)
3. Проверь консоль на ошибки
4. Перезагрузи приложение и браузер

### Уведомления с ошибками
**Проблема:** В консоли видны ошибки уведомлений.

**Решения:**
1. Убедись, что Service Worker активен (Application → Service Workers)
2. Перерегистрируй Service Worker: откройка Параметры → Очистить кэш
3. Откройи консоль Service Worker и проверь логи

### На iOS уведомления не работают
**Проблема:** Safari на iOS не поддерживает Web Notifications API полностью.

**Решение:** Это ограничение iOS. Используй другой браузер или Android.

### Звук из уведомлений раздражает
**Решение:** Отключи звук в параметрах браузера (см. выше).
