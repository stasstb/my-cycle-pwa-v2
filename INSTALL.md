# 📲 Установка приложения "Мій цикл"

Приложение работает как **Progressive Web App (PWA)**, что означает, что его можно установить прямо с браузера на главный экран.

## 🔗 Доступ к приложению

### Онлайн (если у вас есть хостинг)
Скопируй все файлы на сервер и открой в браузере.

### Локально (без интернета)
1. Скачай все файлы
2. Запусти простой HTTP сервер:
   ```bash
   python3 -m http.server 8000
   # или
   npx http-server
   ```
3. Открой в браузере: `http://localhost:8000`

## 📱 Android (Chrome, Edge, Opera)

### Способ 1: Через меню браузера (Рекомендуется)

1. Открой приложение в **Chrome** (или Edge/Opera)
2. Нажми **меню** (три точки внизу справа)
3. Выбери **"Установить приложение"** или **"Add to Home screen"**
4. Нажми **"Установить"**
5. Приложение появится на главном экране
6. Браузер попросит разрешить уведомления — нажми **"Разрешить"**

### Способ 2: Через адресную строку (Chrome)

1. Открой приложение в Chrome
2. В адресной строке появится кнопка **"Установить"** (или иконка монитора)
3. Нажми на неё
4. Следуй инструкциям

### Способ 3: Вручную (для опытных)

1. Откройи DevTools (F12)
2. Console → вставь:
   ```javascript
   if (window.deferredPrompt) {
     window.deferredPrompt.prompt();
   }
   ```

### Разрешить уведомления на Android

После установки браузер попросит разрешение на уведомления:

```
"Мій цикл" хочет отправлять уведомления?
[Разрешить] [Запретить]
```

Нажми **"Разрешить"**, чтобы получать напоминания.

Если случайно нажал "Запретить":
1. Откройи настройки телефона
2. Найди Chrome/Edge
3. Перейди в **Приложения → Уведомления → Мій цикл**
4. Включи уведомления

## 🍎 iOS (Safari)

iOS не полностью поддерживает PWA, но можно добавить приложение на главный экран.

### Установка на главный экран

1. Открой приложение в **Safari**
2. Нажми кнопку **"Поділитися"** (внизу по центру)
3. Прокрути вверх и найди **"На екран 'Домой'"** (или **"Add to Home Screen"**)
4. Нажми на неё
5. Введи имя приложения (может быть любое)
6. Нажми **"Додати"** (или **"Add"**)
7. Приложение появится на главном экране

### Разрешить уведомления на iOS

После открытия приложения Safari попросит разрешение:

```
"Мій цикл" хочет отправлять уведомления?
[Не разрешати] [Разрешити]
```

Нажми **"Разрешити"**.

Если случайно отклонил:
1. **Параметри → Уведомлення → Мій цикл**
2. Включи уведомления

### Примечание для iOS
- Поддержка PWA на iOS ограничена (Safari не кэширует так же как Chrome)
- Оффлайн-функции могут работать не идеально
- Рекомендуется использовать Chrome для лучшей работы

## 🖥️ Windows (Chrome, Edge)

### Установка на Рабочий стол

1. Открой приложение в **Chrome** или **Edge**
2. Нажми **меню** (три точки в правом верхнем углу)
3. Выбери **"Другие инструменты" → "Создать ярлык"** (или **"Install app"**)
4. В диалоге отметь **"Открыть в окне приложения"**
5. Нажми **"Создать"**
6. Приложение откроется в отдельном окне
7. Ярлык появится на Рабочем столе

### Разрешить уведомления

1. Откройи приложение
2. Windows попросит разрешение → нажми **"Да"**

Если не появилось:
1. Параметры → Система → Уведомления и действия
2. Найди приложение в списке
3. Включи уведомления

### Закрепить на Панель задач

1. Кликни правой кнопкой мыши на окне приложения
2. Выбери **"Закрепить на панель задач"**

## 🍎 macOS (Safari, Chrome)

### Способ 1: Safari (встроенный, проще)

1. Открой приложение в **Safari**
2. Нажми **Файл → Добавить значок на Dock**
3. Приложение появится на Dock
4. macOS попросит разрешение на уведомления → **"Разрешить"**

### Способ 2: Chrome (лучше работает)

1. Открой приложение в **Chrome**
2. Нажми **Chrome → Инструменты → Создать ярлык приложения**
3. Отметь **"Открыть в окне приложения"**
4. Нажми **"Создать"**
5. Приложение откроется в отдельном окне
6. Добавь на Dock: **Файл → Добавить значок на Dock**

### Разрешить уведомления

macOS попросит разрешение автоматически. Нажми **"Разрешить"**.

Если нужно изменить позже:
1. **Параметры системы → Уведомления**
2. Найди Chrome/Safari в списке
3. Включи уведомления

## 🐧 Linux (Chrome, Firefox, Edge)

### Chrome/Chromium/Edge

1. Открой приложение в браузере
2. В адресной строке нажми кнопку **установки**
3. Выбери **"Установить приложение"**
4. Приложение добавится в меню приложений

### Firefox

Firefox пока не поддерживает PWA установку (в стадии разработки).  
Решение: используй закладку или установи Chrome.

### Добавить в меню приложений

Автоматически добавится в меню приложений после установки:
- Нажми кнопку меню (внизу слева)
- Найди **"Мій цикл"** в списке

### Разрешить уведомления

1. Браузер попросит разрешение
2. Нажми **"Разрешить"**

Если нужно изменить:
- Chrome: Параметры → Конфиденциальность → Уведомления
- Firefox: (не поддерживает уведомления Web Notifications полностью)

## ⚙️ Первое запуск приложения

Когда ты открыл приложение в первый раз:

1. ✅ Браузер запросит **разрешение на уведомления**  
   → Нажми **"Разрешить"** (можно отключить позже)

2. 📊 Приложение загрузит **хранилище данных**  
   → Ты увидишь логи в консоли

3. 🎯 Приложение покажет **экран "Начни День 1"**

4. 🧡 Нажми **"Почати цикл сьогодні"** — и начнется отсчет!

5. 📖 Также можешь открыть **PDF-руководство** для изучения техник

## 🆘 Решение проблем при установке

### "Кнопка установки не появляется"
- Убедись, что используешь поддерживаемый браузер (Chrome, Edge, Opera)
- На iOS используй Safari
- Перезагрузи страницу (Ctrl+F5)
- Проверь, что Service Worker активен (DevTools → Application → Service Workers)

### "Уведомления не работают"
- Проверь разрешение браузера (замок в адресной строке)
- Проверь уведомления ОС (Параметры → Уведомления)
- Перезагрузи приложение
- См. подробно: [NOTIFICATIONS.md](NOTIFICATIONS.md)

### "Ярлык не создается"
- Перезагрузи браузер полностью
- Очисти кэш браузера
- Попробуй другой браузер (Chrome вместо Edge)
- На iOS используй именно Safari

### "Данные потеряны после переустановки"
- Приложение хранит данные локально в браузере
- При переустановке браузера данные могут потеряться
- Это нормально — используй резервную копию если была сделана
