# 🔐 Безопасное хранилище данных PWA

## 📋 Что было изменено

Приложение **Мій цикл** было обновлено для защиты критически важных данных от случайной очистки при удалении истории браузера.

### Проблема (до обновления)
- Данные хранились только в `localStorage`
- Очистка истории браузера → удаление куки/кэша → потеря всех данных приложения
- Нет возможности запросить постоянное хранилище

### Решение (после обновления)
✅ **IndexedDB** — основное надежное хранилище  
✅ **Storage Manager API** — запрос постоянного хранилища  
✅ **Backup в localStorage** — fallback на случай проблем с IndexedDB  
✅ **Автоматическая миграция** — перенос старых данных из localStorage  
✅ **Логирование** — отслеживание статуса хранилища  

---

## 📁 Новые файлы

### `storage.js` — Модуль безопасного хранения данных

**Основные функции:**

```javascript
// Инициализация (вызывается автоматически)
await StorageManager.initialize();

// Получить данные
const data = await StorageManager.get("cycleData");

// Сохранить данные
await StorageManager.set("cycleData", data);

// Проверить статус постоянного хранилища
const isPersistent = StorageManager.getPersistentStatus();
```

**Что происходит при инициализации:**

1. **Инициализация IndexedDB** — создание БД для хранения данных
2. **Запрос постоянного хранилища** — браузер просит разрешение у пользователя
3. **Проверка статуса** — определяет, защищены ли данные от автоматического удаления
4. **Миграция данных** — переносит старые данные из localStorage в IndexedDB

## 🔍 Поведение браузера

### Когда данные удаляются

❌ **Ручная очистка история** → Браузер → Параметры → "Очистить историю"  
   - Удаляет: localStorage, sessionStorage, IndexedDB, Service Worker кэш

❌ **Автоматическая очистка** → Браузер заполнен, место заканчивается  
   - Удаляет данные редко посещаемых сайтов

### Когда данные НЕ удаляются

✅ **Постоянное хранилище активировано** → Данные защищены от автоматического удаления  
   (но ручная очистка все еще удалит)

✅ **IndexedDB вместо localStorage** → Больше места (обычно 50+ МБ вместо 5-10 МБ)

✅ **Service Worker кэш** → Физические файлы приложения остаются (UI работает оффлайн)

## 🛡️ Storage Manager API

### Что делает запрос постоянного хранилища?

```javascript
if (navigator.storage && navigator.storage.persist) {
  const granted = await navigator.storage.persist();
  
  if (granted) {
    console.log("✓ Браузер не удалит данные при нехватке места");
  } else {
    console.log("⚠ Пользователь отклонил или браузер не разрешил");
  }
}
```

### Когда браузер просит разрешение?

- При первом посещении приложения
- В консоли браузера или через UI браузера (зависит от реализации)

### Что пользователь видит?

Зависит от браузера:
- **Chrome/Edge**: Может показать запрос разрешения
- **Firefox**: Может показать в настройках
- **Safari (iOS)**: Обычно автоматически разрешает для PWA на главном экране

## 📊 Статус хранилища

### Как узнать статус?

**В консоли браузера (DevTools → Console):**

```javascript
// Проверить, активировано ли постоянное хранилище
navigator.storage.persisted().then(persistent => {
  console.log("Постоянное хранилище:", persistent ? "✓ Да" : "✗ Нет");
});

// Проверить расчетное место
navigator.storage.estimate().then(estimate => {
  console.log(`Используется: ${estimate.usage} байт`);
  console.log(`Доступно: ${estimate.quota} байт`);
  const percent = (estimate.usage / estimate.quota * 100).toFixed(2);
  console.log(`Заполнено: ${percent}%`);
});
```

## 💾 Как работает сохранение?

### Процесс сохранения данных

```
save() → IndexedDB + localStorage
         ↓
      Данные в обоих хранилищах
         ↓
      Исчезают при ручной очистке (если не постоянное)
      Исчезают при автоочистке (если не постоянное)
```

### Процесс загрузки данных

```
load() → Проверить IndexedDB
         ↓
      Если есть → Использовать оттуда
      Если нет → Проверить localStorage
                 ↓
              Если есть → Загрузить оттуда
              Если нет → Данных нет (новый пользователь)
```

## 🚀 Рекомендации для пользователей

### Как защитить свои данные?

1. **Разрешить постоянное хранилище**
   - Браузер может попросить разрешение при открытии приложения
   - Рекомендуем выбрать "Разрешить"

2. **Добавить приложение на главный экран (iOS/Android)**
   - Браузер обычно автоматически разрешает постоянное хранилище для PWA
   - iOS: Поделиться → На экран "Домой"
   - Android: Меню → Установить приложение

3. **Не очищать данные сайтов при очистке истории**
   - Если очищаете историю браузера, снимите галочку с "Файлы куки и другие данные сайтов"

4. **Регулярно проверять консоль**
   - Откройте DevTools (F12)
   - Перейдите на вкладку Console
   - Проверьте, есть ли ошибки при загрузке данных

## 🔧 Для разработчиков

### Структура IndexedDB

- **Имя БД:** `miy-cykl-db`
- **Версия:** 1
- **Object Store:** `appData`

### Ключи данных

- `cycleData` — информация о цикле (дата начала, пауза и т.д.)
- `cycleMarks` — отметки прогресса по упражнениям

### Если нужно очистить все данные

**В консоли браузера:**

```javascript
// Очистить IndexedDB
await StorageManager.deleteIndexedDB("cycleData");
await StorageManager.deleteIndexedDB("cycleMarks");

// Или полностью удалить БД
indexedDB.deleteDatabase("miy-cykl-db");

// Очистить localStorage (для полной очистки)
localStorage.removeItem("cycleData");
localStorage.removeItem("cycleMarks");
localStorage.removeItem("_migrated_cycleData");
localStorage.removeItem("_migrated_cycleMarks");
```

### Как добавить новые данные для сохранения?

1. Определить ключ для данных: `"myDataKey"`
2. Сохранить: `await StorageManager.set("myDataKey", data)`
3. Загрузить: `const data = await StorageManager.get("myDataKey")`
4. При инициализации добавить в `loadAppData()` функцию

## 🐛 Решение проблем

### Проблема: Данные не сохраняются
**Решение:** Проверьте консоль браузера на ошибки. Убедитесь, что StorageManager инициализирован перед save().

### Проблема: IndexedDB не работает
**Решение:** Убедитесь, что браузер поддерживает IndexedDB и не заблокирован. Проверьте настройки приватности браузера.

### Проблема: Данные удалились после очистки истории
**Решение:** Это ожидаемое поведение. Разрешите постоянное хранилище и не очищайте "Файлы куки и другие данные сайтов" при очистке истории.

### Проблема: Не вижу логов инициализации
**Решение:** Откройте консоль браузера (F12 → Console). Может быть включен фильтр по уровню логирования. Перезагрузите страницу.
