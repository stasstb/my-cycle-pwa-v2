# Журнал змін (CHANGELOG)

## [1.1.0] — 2026-08-17

### Добавлено
- ✅ **Система уведомлений** (Web Notifications API)
  - Напоминание в 09:00 "Добрий день!"
  - Напоминание в 18:00 о текущем дне программы
  - Напоминание в 21:00 "Последний звонок"
  - Уведомление о статусе хранилища при первом запуске

- ✅ **Интеграция с Service Worker**
  - Обработка отправки уведомлений через postMessage
  - Клик по уведомлению открывает/фокусирует приложение
  - Логирование закрытия уведомлений

- ✅ **Запрос разрешений**
  - Браузер запрашивает разрешение на уведомления при первом запуске
  - Пользователь может отключить уведомления в любой момент

- ✅ **Документация**
  - README.md с полным описанием приложения
  - Технические детали архитектуры
  - Инструкции по установке и использованию
  - Руководство по разработке

### Улучшено
- Функция `initializeApp()` расширена поддержкой уведомлений
- Консоль содержит детальные логи для отладки
- Лучшая интеграция между браузером и Service Worker

### Иправлено
- Нет критических исправлений в этой версии

## [1.0.0] — (Начальная версия)

### Содержит
- ✅ 6 программ тренировок (Вульва, Клітор, Вульва+Клітор, Зона G, Зона К, Поддержка)
- ✅ Система лічення днів с поддержкой паузы менструации
- ✅ Чек-лист кроків для каждого дня
- ✅ Прогресс-бар с процентом выполнения
- ✅ PDF-руководство с техниками массажа и дыхания
- ✅ Безопасное хранилище данных (IndexedDB + localStorage + Storage Manager API)
- ✅ Полная поддержка PWA (установка на главный экран, оффлайн)
- ✅ Адаптивный дизайн для мобилей и десктопа
