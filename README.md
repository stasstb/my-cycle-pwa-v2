# 🧡 Пробуждение

Мобильное PWA-приложение для последовательных практик массажа, дыхания и отслеживания личного прогресса. Приложение работает без сборки и хранит данные локально на устройстве.

## Возможности

- Пять учебных программ: **Вульва**, **Клитор**, **Вульва + клитор**, **Зона G** и **Зона К**.
- Отдельный режим **Поддержание** с выбором одного или двух дней недели и календарём практик.
- Календарь программы с текущим днём, днями отдыха и отметками выполнения.
- Чек-лист шагов практики: дыхание, подготовка, лубрикант или крем, массаж и отдых.
- Прогресс выбранной зоны в верхней части экрана.
- Заметки после завершённой практики и готовые варианты результата.
- Пауза цикла на время менструации с остановкой счётчика и продолжением со следующего дня цикла.
- Встроенное пособие «Массаж + дыхание» в формате PDF.
- Напоминания в 09:00, 18:00 и 21:00, если браузер поддерживает уведомления и разрешение выдано.
- Экспорт и импорт данных в формате JSON.
- Раздел «Справка» с подробными инструкциями по установке и использованию приложения.
- Быстрая навигация: кнопки справки и настроек в шапке, кнопка возврата наверх в футере.
- История циклов с возможностью удалить отдельную завершённую запись.
- Одноразовая подсказка установки при первом открытии сайта в обычном браузере.
- Офлайн-загрузка приложения после первого открытия благодаря Service Worker.

## Установка

Для полноценной установки приложение должно быть опубликовано по HTTPS. `localhost` подходит только для разработки.

### Android

1. Открой сайт в Chrome.
2. Выбери `Установить приложение` или `Добавить на главный экран`.
3. Разреши уведомления, если они нужны.

### iPhone

1. Открой сайт в Safari.
2. Нажми `Поделиться`.
3. Выбери `На экран «Домой»`.
4. Запусти приложение с домашнего экрана. Уведомления зависят от версии iOS и настроек Safari.

При первом открытии приложение само покажет краткую подсказку по установке. Она отображается один раз на устройстве и не показывается, если приложение уже запущено в установленном режиме.

### Linux и desktop

Для локального запуска используй Python:

```bash
python3 -m http.server 8000
```

Затем открой <http://localhost:8000>.

## Как пользоваться

1. В верхних вкладках выбери программу: «Вульва», «Клитор», «Вульва + клитор», «Зона G» или «Зона К».
2. Нажми `Начать цикл`. День 1 начнётся сегодня, а следующие дни будут рассчитаны автоматически.
3. Открой текущий день в календаре и прочитай описание, длительность и подсказку по подготовке.
4. Выполни шаги практики по порядку и отметь их в чек-листе.
5. Нажми `Завершить день`. Прогресс обновится, а приложение вернёт тебя к календарю.
6. После завершения добавь заметку о самочувствии и выбери результат занятия.
7. Если началась менструация, используй `Поставить на паузу`: номер текущего дня зафиксируется, и дни не будут считаться дальше. После окончания нажми `Продолжить цикл`, чтобы сегодняшний день стал следующим днём цикла.
8. Для регулярных занятий открой `Поддержание` и выбери один или два дня недели.

В шапке доступны кнопки `?` и `⚙` для перехода к справке и настройкам. Кнопка `↑` в футере возвращает экран в начало.

## Данные и резервная копия

История хранится в браузере устройства через IndexedDB с резервным использованием `localStorage`. Приложение также запрашивает постоянное хранилище, если это поддерживается браузером.

Очистка истории, данных сайтов или хранилища браузера может удалить историю приложения. Перед такой очисткой:

1. Открой блок `Настройки`.
2. Нажми `Экспорт` и сохрани JSON-файл.
3. После очистки открой `Настройки` → `Импорт` и выбери этот файл.

Резервная копия содержит текущий цикл, отметки, историю циклов, выбранную программу и настройки календаря поддержания. Файл хранится на устройстве пользователя; приложение не отправляет эти данные на сервер.

В разделе `История циклов` можно раскрыть завершённую запись, посмотреть сохранённые заметки и удалить её кнопкой `×`. Удаление требует подтверждения и не влияет на текущий активный цикл.

## Обновление приложения

Текущая версия: **2.0.28**.

Номер версии отображается в шапке приложения. Service Worker проверяет обновления при запуске, загружает HTML без старого HTTP-кэша и автоматически активирует новый кэш. Обычно ручная очистка истории браузера не требуется.

При публикации нового релиза необходимо синхронно обновить:

- `APP_VERSION` в `app.js`;
- `APP_VERSION` и версии ресурсов в `sw.js`;
- query-параметры ресурсов в `index.html`;
- номер версии в резервном формате, если изменяется структура данных.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `index.html` | HTML-оболочка, manifest и подключение скриптов |
| `app.js` | Интерфейс, программы, календарь, прогресс, уведомления и импорт/экспорт |
| `storage.js` | IndexedDB, `localStorage` и постоянное хранилище |
| `styles.css` | Стили интерфейса и адаптивная разметка |
| `sw.js` | Офлайн-кэш и обновление PWA |
| `manifest.webmanifest` | Название, иконки и параметры установки |
| `diagnostic.js` | Диагностика состояния хранилища |
| `probuzhdenie-zones-guide.pdf` | Встроенное пособие по массажу и дыханию |
| `icons/` | Иконки приложения |

## Проверка перед публикацией

```bash
node --check app.js
git diff --check
python3 -m http.server 8000
```

После публикации проверь установку отдельно на Android и iPhone: правила отображения приглашения к установке и поддержки уведомлений зависят от браузера и версии операционной системы.
