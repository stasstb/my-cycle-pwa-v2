# 🧡 Мой цикл — Программа массажа и дыхания

Мобильное PWA-приложение для отслеживания и управления циклом тренировок массажа и дыхательных практик. Разработано с акцентом на приватность, надежность и доступность.

## 📱 Возможности

### Основное
- **Счетчик дней** — Автоматически отслеживает дни от начала цикла
- **6 программ обучения** — Вульва, Клитор, Вульва+Клитор, Зона G, Зона К, Поддержание
- **Планирование дней** — Каждый день имеет четкую инструкцию и временное расписание
- **Чек-лист шагов** — Отмечай шаги по мере выполнения: дыхание → лубрикант → массаж
- **Прогресс** — Видимый прогресс в верхней полосе и статистика выполненных дней

### Управление циклом
- **Пауза менструации** — Временно приостанови счетчик дней во время менструации
- **Новый цикл** — Начни новый цикл в любой момент
- **Локальное хранение** — Данные сохраняются локально в браузере

### Инструкции
- **Встроенный PDF** — Пособие по массажу и дыханию (6 страниц)
- **Напоминания для каждого дня** — Подготовка, лубрикант, техника
- **Адаптивные советы** — В зависимости от программы и дня

### Оповещения
- **09:00 — Добрый день** — Напоминание о начале дня
- **18:00 — Вечер** — Напоминание о текущем дне и статусе выполнения
- **21:00 — Последний звонок** — Финальное напоминание перед сном
- **Статус хранилища** — Предупреждение о безопасности данных

## 🚀 Установка

### На смартфон (Android)
1. Открой приложение в Chrome
2. Нажми меню (три точки) → "Установить приложение"
3. Приложение появится на экране "Домой"
4. Разреши уведомления

### На iPhone (iOS)
1. Открой в Safari
2. Нажми "Поделиться" (внизу)
3. Нажми "На экран «Домой»"
4. Дай приложению имя и добавь
5. Разреши уведомления в Параметры → Уведомления

### На компьютер
- Просто открой в браузере на desktop
