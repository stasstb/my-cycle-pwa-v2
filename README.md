# 🧡 Мій цикл — Програма масажу та дихання

Мобільне PWA-приложение для відстеження та управління циклом тренувань масажу та дихальних практик. Розроблено з акцентом на приватність, надійність та доступність.

## 📱 Можливості

### Основне
- **Лічильник днів** — Автоматично відстежує дні від початку циклу
- **6 програм навчання** — Вульва, Клітор, Вульва+Клітор, Зона G, Зона К, Поддержка
- **Планування днів** — Кожен день має чітку інструкцію та часовий розклад
- **Чек-лист кроків** — Відмічай кроки по мірі виконання: дихання → лубрикант → масаж
- **Прогресс** — Видимий прогрес у верхній смузі та статистика виконаних днів

### Управління циклом
- **Пауза менструації** — Тимчасово припини лічильник днів під час менструації
- **Новий цикл** — Почни новий цикл будь-якої миті
- **Нееphemeрне зберігання** — Дані зберігаються локально в браузері

### Інструкції
- **Вбудований PDF** — Посібник з масажу та дихання (6 сторінок)
- **Нагадування для кожного дня** — Підготовка, лубрикант, техніка
- **Адаптивні поради** — Залежно від програми та дня

### Оповіщення
- **09:00 — Добрий день** — Напоминание о начале дня
- **18:00 — Вечер** — Напомин о текущем дне и статусе выполнения
- **21:00 — Последний звонок** — Финальное напоминание перед сном
- **Статус хранилища** — Предупреждение о безопасности данных

## 🚀 Установка

### На смартфон (Android)
1. Открой приложение в Chrome
2. Нажми меню (три точки) → "Установить приложение"
3. Приложение появится на экране "Домой"
4. Разреши уведомления

### На iPhone (iOS)
1. Открой в Safari
2. Нажми "Поділитися" (внизу)
3. Нажми "На екран «Домой»"
4. Дай приложению имя и добавь
5. Разреши уведомления в Параметры → Уведомления

### На компьютер
- Просто открой в браузере на desktop

## 🔧 Технические детали

### Архитектура
```
app.js          → Основная логика приложения (программы, календарь, состояние)
storage.js      → Система хранения данных (IndexedDB + localStorage + Storage API)
sw.js           → Service Worker (оффлайн, кэширование, уведомления)
styles.css      → Адаптивный дизайн для мобилей и десктопа
manifest.webmanifest → Настройки PWA
index.html      → HTML-оболочка
diagnostic.js   → Утилиты для диагностики
```

### Состояние (State)
```javascript
cycle {
  start: "2026-08-17"      // Дата начала цикла (ISO)
  paused: false            // В ли пауза?
  pauseStart: "2026-08-18" // Дата начала паузы
  pausedDays: 3            // Количество дней паузы
}

marks {
  "vulva_0": true          // День 0 программы "vulva" выполнен
  "vulva_0_steps": [true, true, false] // Статус каждого шага
}

activeProgram: "vulva"     // Текущая программа
```

### Хранилище
- **IndexedDB** — Основное хранилище (большой объем, надежное)
- **localStorage** — Резервное хранилище (мини-БД браузера)
- **Storage Manager API** — Запрос постоянного хранилища (защита от автоочистки)

**Важно:** Данные будут удалены, если пользователь:
- Вручную очистит "Файлы cookies и другие данные сайтов"
- Удалит приложение полностью
- Отключит хранилище в Параметры браузера

Но **не будут** удалены при:
- Очистке истории (если не выбрана опция данных сайтов)
- Переустановке браузера (на некоторых ОС)

### Программы
Каждая программа состоит из 7-9 дней:
```javascript
{
  id: "vulva",
  title: "Вульва",
  description: "8 днів. Масаж через день.",
  days: [
    ["Вульва", "8 хв", "vulva"],    // [Название, Время, Тег]
    ["Відпочинок", "", "rest"],
    ...
  ]
}
```

### Система нагадування
- **Ежедневные напоминания** — Проверяют время каждую минуту
- **Адаптивные сообщения** — Содержат информацию о текущем дне и программе
- **Интегрированы с Service Worker** — Работают, даже если браузер в фоне
- **Кликабельны** — Открывают приложение при клике

## 📊 Прогресс

**Общий прогресс** = (Завершено дней) / (Всього дней всех программ) × 100%

Программы:
- Вульва: 8 дней
- Клітор: 9 дней
- Вульва+Клітор: 7 дней
- Зона G: 7 дней
- Зона К: 7 дней
- Поддержка: 5 дней

**Итого: 43 дня**

## 🔐 Приватность и безопасность

✅ **Что говорит в пользу приватности:**
- Нет подключения к интернету (работает оффлайн)
- Нет учетной записи или входа
- Нет сервера, который получает ваши данные
- Данные хранятся только в браузере
- Можешь удалить приложение и все данные сразу

⚠️ **На что стоит обратить внимание:**
- Данные находятся на устройстве (не облако)
- Если потеряю устройство, потеряю данные
- Если очищу данные браузера, потеряю прогресс
- Синхронизация между устройствами невозможна

## ⚡ Быстрый старт для пользователя

1. **Открыть приложение** в браузере или установить на главный экран
2. **Разрешить уведомления** — браузер попросит один раз
3. **Нажать "Начать цикл"** — приложение запомнит дату
4. **Выбрать программу** — жми на вкладку с названием
5. **Открыть день** — жми на карточку дня
6. **Отметить шаги** — чекбоксы во время выполнения
7. **Завершить день** — жми "✓ Завершити день"
8. **Повторять ежедневно** — приложение напомнит тебе
